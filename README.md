## Projets

**[OneMoreRep](https://github.com/slayerfx/onemorerep)** · **[démo en ligne](https://onemorerep.infinityfree.io)**

Site de musculation en PHP 8 : bibliothèque d'exercices, création de programmes d'entraînement et calculateur de dépense énergétique (Mifflin-St Jeor). Architecture MVC écrite sans framework, MySQL via PDO en requêtes préparées, tests PHPUnit.

**[SoundGrab](https://github.com/slayerfx/soundgrab)**

Téléchargeur SoundCloud à interface web locale. FastAPI + yt-dlp, progression poussée en Server-Sent Events, interface sans build ni dépendance externe. 36 tests, lint ruff, CI sur Windows et Linux.
